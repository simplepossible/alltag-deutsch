# Alltag Deutsch

A small browser app for everyday German, from A1 to B2. Each sitting is one short scene: hear the line, spell it, then answer three checks.

Progress stays in this browser (`localStorage`). A different phone or browser starts empty.

## Run it

```bash
npm install
npm run dev
```

Open the address Vite prints, usually http://localhost:5173/.

`npm run check` verifies the scenes, placement, and level movement.
